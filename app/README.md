# Narrative prototype

This dependency-free prototype implements the first two scenes of the planned
interactive article:

1. release a one-tonne carbon dioxide pulse and follow the fraction remaining;
2. connect the persistent atmospheric burden to Earth's energy imbalance and
   the observed distribution of Earth-system energy uptake.

Serve the repository over HTTP from its root:

```shell
uv run python -m http.server 8000
```

Then open <http://localhost:8000/app/>.

The browser loads `data/co2-pulse.json`, so opening `index.html` directly as a
local file is not supported. No build step or JavaScript package installation
is required for this prototype.

## Scientific status

The pulse curve is generated by the tested Python implementation in
`src/radiativeforcing/ar6/co2.py`. It reproduces the CO2 branch of the pinned
IPCC AR6 WGI Chapter 7 metric generator, including the Joos et al. atmospheric
response retained by AR6, the Meinshausen forcing relationship, the assessed
5% rapid adjustment, and the AR6 two-timescale temperature response.

The generated browser file contains forcing and temperature series, but the
opening deliberately displays only atmospheric persistence. Those quantities
are introduced in subsequent narrative scenes rather than simultaneously.

The 91% ocean, 5% land, 3% ice loss, and 1% atmosphere shares describe the
observed global energy inventory change assessed by AR6 for 1971–2018. They do
not trace the fate of energy caused by the illustrative one-tonne pulse.
